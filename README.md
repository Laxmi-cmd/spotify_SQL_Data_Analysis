Retail Sales Analysis using SQL
Project Overview
This project analyzes retail sales data using SQL to understand sales performance, profitability, customer behavior, and product performance.
Tools Used
SQL
SQLite
Analysis Performed
Overall sales and profit analysis
Sales by product category
Customer sales analysis
Regional sales and profit analysis
Top 5 products by sales
Loss-making product identification
Product ranking using a SQL window function
Average Order Value (AOV)
Most profitable category analysis
Key Insights
Total sales: 164,500
Total profit: 16,300
Technology was the most profitable category.
Furniture generated an overall loss.
The West region had the highest sales.
Sofa and Table were loss-making products.
